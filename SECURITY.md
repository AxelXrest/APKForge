# Security reports

For a suspected vulnerability, use the repository's **Security → Report a
vulnerability** option if available. If private reporting is unavailable, ask the
maintainer for a private contact without posting exploit details or secrets in a
public issue. This project has no guaranteed response time or support window.

Include the affected version, a minimal reproduction, impact, and relevant
sanitized logs. Never attach signing credentials or private APKs.

APKForge runs locally installed tools and processes APKs with those tools. Use
trusted tool sources and keep them updated. Download checksums are verified when
published by the provider; a checksum from the same provider is an integrity
check, not an independent authenticity guarantee. The automatically created
development signing key is public-purpose test material and must not be used as
a production signing identity.
